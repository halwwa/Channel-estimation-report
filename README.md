# Channel Estimation and Equalization / Оценивание каналов связи и эквализация сигналов

## О проекте
Учебный отчет по производственной практике. В работе исследуются свойства беспроводных каналов связи, многолучевое распространение, а также рассматриваются методы оценивания импульсной характеристики канала.
